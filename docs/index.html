Architecture Overview

1. Overview & Freestanding Principles

Anastasia v7.1 is an embeddable, adaptive, bare-metal, zero-CRT compiler ecosystem and execution engine for Anastasia Assembly (.ana). Designed for maximum execution throughput, zero runtime overhead, adaptive dynamic tiering, non-temporal data streaming, and zero-copy hardware I/O.

Freestanding Execution Policy: Operates exclusively under GCC/Clang freestanding flags (-ffreestanding -nostdlib -fno-exceptions -fno-rtti) with direct assembly syscall boundaries (raw_mmap, raw_mprotect, raw_write, raw_clone, raw_futex, raw_io_uring). Completely purges external dependencies like asmjit or libc.

Features native string literals with parse-time zero-copy length tracking, an AOT relocatable ELF generator (ElfEmitter) that acts as its own linker, and pluggable backends for x86_64 AVX-512 and AArch64 ARM64.

Memory Subsystem

3. Memory Subsystem & TLAB Architecture

Fast-path Thread-Local Allocation Buffer (tlab_allocate) performing branchless bump pointer allocations. Overruns are guarded by PROT_NONE pages; overruns trigger a freestanding SIGSEGV fault handler to allocate new 64 KB TLAB slabs transparently.

Zero Heap Allocations via Escape Analysis: Single-pass SSA escape analysis pass (run_escape_analysis) scalar-replaces short-lived new-instance allocations directly into virtual registers/stack slots, achieving 0 heap allocations for non-escaping objects.
Register Spilling

4. Register Model & Stack Spilling Rules

Anastasia supports unbounded virtual registers (v0..vN). Virtual registers are mapped dynamically to System V AMD64 / Win64 / AAPCS64 physical registers or stack spill slots:

Virtual Register Range Storage Kind x86_64 Physical Hardware Location
p0..p5Parameter%rdi, %rsi, %rdx, %rcx, %r8, %r9
v0..v4Scratch Register%rax, %rdx, %r8, %r9, %r10
v5..vNStack Spill SlotAllocated dynamically at [rbp - 8*N]
ymm0..zmm31SIMD Vector256-bit YMM and 512-bit ZMM vector files
AOT Codegen

5. Standalone Zero-Linker AOT Emitter

Dual emission targets via AnaTargetBackend: MemoryTarget (JIT executable pages), ElfEmitter (relocatable 64-bit ELF object files with symbol tables and relocations), and PeEmitter (native 64-bit Windows PE32+ executables).

ElfEmitter acts as its own native linker by emitting .rodata sections and patching RIP-relative relocations (R_X86_64_PC32 / R_AARCH64_ADR_PREL_PG_HI21) without needing external tools like ld or link.exe.

Anastasia Engine v7.1 is a high-throughput, bare-metal JIT & AOT compiler engine for a RISC-style intermediate assembly language called Anastasia Assembly (.ana). It compiles .ana code directly into native x86_64 (AVX2 / AVX-512) and ARM64 machine code with zero dynamic C-runtime dependencies.
The engine is compiled under -ffreestanding -nostdlib -fno-exceptions -fno-rtti. It completely bypasses standard C libraries (libc / libstdc++) and executes raw Linux/Win32 kernel syscalls directly via inline assembly (raw_mmap, raw_write, raw_clone, raw_futex).
