Zero-Linker ELF & PE Emitter

SSA AVX-512 Vectorization

Zero-Copy Hardware io_uring

Technical Reference

Engine Documentation & Architecture

In-depth technical breakdown of Anastasia's registers, ABI, and codegen pipeline.

Register & Type Model

  • Virtual Registers: Unbounded register set v0..vN managed by linear-scan allocator (AnaRegAlloc).
  • Type Tagging: Native primitive types: i32, i64, f32, f64, ptr, v128, v256, v512, string.
  • Spilling Strategy: Automatic spill code generation (mov [rsp+N], reg) when live range pressure exceeds physical CPU registers.

Memory & TLAB Allocator

  • Bump Pointer TLAB: Branchless 64 KB Thread-Local Allocation Buffer (tlab_allocate).
  • VM Guard Pages: Buffer overruns trigger transparent signal handler guard pages (PROT_NONE) with 0 crash.
  • Escape Analysis: Temporary short-lived objects are scalar-replaced directly into virtual registers (0 heap allocs).

AOT Zero-Linker Emitter

  • Standalone ELF Emitter: ElfEmitter builds .text, .rodata, .symtab, and .rela.text sections directly in C++.
  • RIP Relocations: Natively patches R_X86_64_PC32 and R_AARCH64_ADR_PREL_PG_HI21 without external linkers (ld).
  • PE32+ Generator: Native Windows 64-bit executable (.exe) emission module.

01_math_basics.ana

Basic register arithmetic, constant additions, and subtraction operations.

.fn math_example(p0: i64, p1: i64) -> i64
    .registers 2 local
    add-int/64 v0, p0, p1
    sub-int/64 v1, v0, 500
    return-val v1
.end_fn
02_vtable_dispatch.ana

Polymorphic virtual method dispatch via Monomorphic Inline Cache (IC).

.fn vtable_dispatch(p0: ptr) -> i64
    .registers 3 local
    load-mem v0, [p0 + 0]       ; vtable ptr
    load-mem v1, [v0 + 16]      ; method slot
    invoke-vmethod v1, [p0]
    move-result v2
    return-val v2
.end_fn
07_hardware_atomics.ana

Hardware lock-free atomic CAS and full memory barrier ordering fences.

.fn lock_free_atomic(p0: ptr, p1: i64) -> i64
    .registers 1 local
    atomic-add/64 [p0 + 0], p1
    fence                       ; Full hardware mfence / sfence
    load-mem v0, [p0 + 0]
    return-val v0
.end_fn

Frequently Asked Questions

Everything you need to know about Anastasia Engine, architecture, and deployment.

Anastasia Engine v7.1 is a high-throughput, bare-metal JIT & AOT compiler engine for a RISC-style intermediate assembly language called Anastasia Assembly (.ana). It compiles .ana code directly into native x86_64 (AVX2 / AVX-512) and ARM64 machine code with zero dynamic C-runtime dependencies.
The engine is compiled under -ffreestanding -nostdlib -fno-exceptions -fno-rtti. It completely bypasses standard C libraries (libc / libstdc++) and executes raw Linux/Win32 kernel syscalls directly via inline assembly (raw_mmap, raw_write, raw_clone, raw_futex).
